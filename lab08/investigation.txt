Exit code was 0 for every FOUND, 3 for the not found, and 2 for
case/logs/missing.log. That is the point of three separate codes - a caller
can tell "nothing there" apart from "something broke".

./investigate.sh case/logs/missing.log admin         exit 2
  Error printed to standard error, file does not exist.

ANSWERS

1. 198.51.100.77 made 15 failed attempts in this log and is NOT in the IOC
list, and the firewall never saw it at all. So the worst-behaving address in
the log is invisible to both the intelligence list and the firewall. An IOC
list only holds what somebody already reported - it cannot find anything new.

2. 203.0.113.200 was blocked by the firewall on port 3389, which is RDP
(Remote Desktop Protocol). But auth.log shows it attacking SSH. One door was
shut and it walked straight to another.

3. 203.0.113.77 appears only in the web log, 12 requests, no login attempts
at all. It was probing web paths rather than trying to log in - a different
kind of attack against a different service.

4. "admin" is a LEGACY account - it is not in the current user list, only in
the old backup. 39 people-hours of guessing spent on an account that should
not exist any more. Removing dead accounts removes the target.
