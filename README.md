# scripting-for-cybersecurity

Practical work for the Scripting for Cybersecurity module, SETU Carlow.

## Labs

Lab 01 - Development environment and Python basics
Lab 02 - Linux command line and the shell environment
Lab 03 - Log analysis with grep, awk, sort and uniq
Lab 04 - File types, searching and comparing files
Lab 05 - Variables, quoting and the first scripts
Lab 06 - Arguments, exit codes and reusable scripts
Lab 07 - Conditionals and classification
Lab 08 - Pattern matching and word-boundary searching
Lab 09 - for loops, hashing and file type analysis
Lab 10 - while loops and safer iteration

Each lab folder contains the scripts for that lab, the outputs they produce,
and an investigation file recording what the evidence showed.
