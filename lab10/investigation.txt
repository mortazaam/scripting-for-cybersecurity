6. A BUG I FIXED
Every log reported 40 lines. I had used the name LINES, which bash uses
for terminal height. Renaming it to LINECOUNT fixed it. Avoid names bash
reserves: LINES, COLUMNS, PATH, HOME, USER, PWD, IFS, RANDOM.

7. WHAT I LEARNED
for is for a list you already know; while carries on until something
changes.
for $(cat file) shreds lines at spaces; while IFS= read -r keeps them whole.
A pipe into a loop makes a subshell, so counters are lost. Use done < <(cmd).
An invisible carriage return makes identical-looking values compare as
different.
A file with no final newline loses its last line unless you add
|| [ -n "$LINE" ].
